## 🚀 Featured Projects

### 🍽️ Restaurant Review Classification Using Naive Bayes
A web-based application that analyzes customer restaurant reviews and classifies them as **positive or negative**, helping users understand feedback and choose restaurants more easily. Reviews are cleaned and converted into numerical features, and a **Naive Bayes** model trained with Scikit-learn predicts the sentiment of any new review. A React frontend sends the review to a FastAPI backend and displays the result, with handling for incorrect or unexpected inputs.

- **Tech Stack:** `Python` `FastAPI` `React` `Pandas` `NumPy` `Scikit-learn`

### 📊 Purchase Order & Vendor Management Report (SAP ABAP)
An SAP ABAP reporting application that lets business users monitor **purchase orders, vendors, materials, quantities, and order values** in one place. Users filter by company code, vendor, material, PO number, and date range, and the results are displayed in an **ALV report**. I built the selection screen, wrote Open SQL joins across tables such as `EKKO`, `EKPO`, `LFA1`, and `MARA`, added input validation and no-data handling, and debugged with the ABAP Debugger.

- **Tech Stack:** `ABAP` `DDIC` `Open SQL` `Internal Tables` `ALV` `BAPI` `CDS Views` (SAP S/4HANA)
